# Code of Conduct

UU Remote Web accepts collaboration in English and Chinese. Keep discussions practical, respectful, and focused on the project.

## Expected behavior

- Describe technical disagreements with evidence and reproducible details.
- Respect contributor and user privacy.
- Use synthetic credentials, device identifiers, addresses, and session data in public examples.
- Keep issues and pull requests relevant to the repository.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing SMS codes, account credentials, tokens, private addresses, session data, or other private user information.
- Deliberately misleading reports, fabricated reproduction steps, spam, or unrelated promotion.

## Enforcement

Maintainers may edit, hide, or remove content and may restrict contributors who repeatedly violate these expectations. Report conduct concerns privately to `iola1999@foxmail.com`.

# 社区行为准则

UU Remote Web 接受中文和英文交流。讨论应保持务实、尊重，并围绕项目本身展开。

## 期望的行为

- 用事实和可复现信息讨论技术分歧。
- 尊重贡献者与用户的隐私。
- 公开示例使用虚构的凭证、设备标识、地址和会话数据。
- Issue 与 Pull Request 保持主题明确。

## 不接受的行为

- 骚扰、威胁、人身攻击或歧视性表达。
- 公开短信验证码、账号凭证、Token、私有地址、会话数据或其他用户隐私。
- 故意误导、伪造复现步骤、发送垃圾内容或无关推广。

## 处理方式

维护者可以编辑、隐藏或移除违规内容，并限制多次违反准则的贡献者。相关问题可发送至 `iola1999@foxmail.com` 私下反馈。
